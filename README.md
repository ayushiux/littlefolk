# Littlefolk

**[Open the character studio](https://ayushiux.github.io/littlefolk/)**

Small prompt. Big personality.

A playful pixel-character design experiment. Describe a creature, color, mood and accessories, save a transparent PNG, then take your character into the twenty-second footer jump game. Click, tap or press Space to start and jump.

This prototype remixes preset pixel parts locally. It does not use an AI generation service, an account or a paid API. Character settings and best score stay in browser local storage.

Open index.html in a modern browser. Keyboard and touch controls, responsive layouts and reduced-motion preferences are supported.
